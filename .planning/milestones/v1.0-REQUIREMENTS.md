# Requirements: Happier (Fork)

**Defined:** 2026-04-18
**Core Value:** Control AI coding agent sessions remotely from any device, with end-to-end encryption.

## v1.0 Requirements — MCP Tool Configuration

### Settings Schema

- [ ] **SCHEMA-01**: User can configure per-tool MCP enable/disable via a `mcpToolsSettingsV1` key in `~/.happier/settings.json` with shape `{ v: 1, tools: { "<tool_name>": { enabled: boolean } } }`
- [ ] **SCHEMA-02**: Tools not listed in config default to `enabled: true` (opt-out model, not opt-in)

### Startup Behavior

- [ ] **STARTUP-01**: MCP server reads `mcpToolsSettingsV1` from `~/.happier/settings.json` once at `startHappyServer` startup (not per-request)
- [ ] **STARTUP-02**: If the settings file is absent or `mcpToolsSettingsV1` key is missing, all tools are enabled (safe default — no breaking change for existing users)
- [ ] **STARTUP-03**: If the config fails Zod validation, all tools are enabled and a `logger.warn` is emitted (graceful fallback, no crash)

### Tool Registration

- [ ] **TOOLS-01**: At MCP server startup, only tools with `enabled: true` (or absent from config) are registered with the `McpServer` instance
- [ ] **TOOLS-02**: Unknown tool names in config are silently handled (debug-level log) so settings files survive tool renames and catalog additions

### Validation Feedback

- [ ] **VALID-01**: Unknown tool names in the config produce a `logger.warn` log entry at startup identifying which names were unrecognized

## Future Requirements

- Per-project `.mcp.json` overrides (project-local config, overrides user-global)
- Wildcard/glob tool name patterns (e.g. `"action_*": { enabled: false }`)
- CLI command to list available tool names (`happier mcp list-tools`)
- Per-surface overrides (disable tool on `session_agent` but keep on `mcp`)

## Out of Scope

| Feature | Reason |
|---------|--------|
| Massive divergence from upstream | Fork goal is incremental features + bug fixes; keeping close to upstream reduces merge conflicts |
| UI for editing settings | Hand-edit only for v1.0; no TUI or GUI settings editor |
| Remote/server-side tool config | Config lives on the machine running the daemon |
| Wildcard tool matching | Flat tool names sufficient for current catalog size |
| `happier-settings.json` separate file | Using `mcpToolsSettingsV1` namespaced key in existing `settings.json` |
| Per-surface filtering for `session_agent` | Only MCP surface in scope for v1.0 |
