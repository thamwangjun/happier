# Milestone v1.1: Session Agent Tools — Global Default

**Status:** ✅ SHIPPED 2026-04-22
**Phases:** 4-5
**Total Plans:** 2

## Overview

Added a `default?: boolean` field to `sessionAgentToolsSettingsV1` so developers can set a baseline enabled/disabled state for all MCP tools not individually configured. The predicate now performs a 3-level lookup: per-tool entry → global `default` → `true` fallback. This preserves the existing opt-out behavior for users with no `default` field, while enabling a clean opt-in mode via `"default": false`.

## Milestone Summary

**Key Decisions:**

- `z.boolean().optional()` without `.default()` on the `default` field — absence is distinguishable from explicit `true` at predicate level
- Predicate fallback is `?? true` not `?? false` — backward-compatible opt-out for users without a `default` field
- JSON key `sessionAgentToolsSettingsV1` in settings.json NOT renamed (per D-03) — only TypeScript identifiers renamed
